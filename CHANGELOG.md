# История изменений

## Не выпущено

- Поддержаны камеры со звуком: аудио удаляется автоматически, видео передаётся и записывается без перекодирования.
- Добавлен короткий адрес JPEG `/<id>.jpg`. Адрес `/snapshots/<id>.jpg` продолжает работать.

## 0.1.0 — 19.09.2026

Первый выпуск DvorCam:

- Docker Compose с автоматическим HTTPS и вариант для своего reverse proxy.
- Пустой список камер при установке. Адрес, логин и пароль задаются в `.env`.
- Добавление камер в админке, WebRTC без перекодирования и NO SIGNAL при потере камеры.
- Архив в готовых MP4, поддержка HEAD/Range и API.
- Хранение в обычной папке. Срок, размер и резерв свободного места настраиваются в админке.
- Сборки amd64 и arm64, готовый комплект для клиентов на Linux amd64.
